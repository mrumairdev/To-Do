# Todo App

Local-first Flutter to-do app built with a clean, maintainable structure.

## Included

- Add, edit, delete, and complete tasks
- Task search by title
- Task categories
- Dark mode stored locally
- Hive-backed persistence
- A clean boundary for future Firebase integration

## Notes

The current milestone focuses on the offline core product described in the requirements.
Firebase is intentionally kept as a future integration point so we can add:

- Authentication
- Cloud sync
- Push notifications
- Calendar integration

once a Firebase project configuration is available.
